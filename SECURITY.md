# Security Policy

FHE Oracle is a testing tool. It is not a certified cryptographic product, and it does not make an FHE system secure.

## Reporting

Report a vulnerability privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Please do not open a public issue.

Please include the affected version or commit, the backend used, a minimal reproduction if you have one, and the expected and observed behaviour.

## Scope

In scope: a flaw in this tool that leads to a wrong or misleading result about the system under test, unsafe handling of the inputs or files it reads, and dependency or packaging problems that affect its users.

Out of scope: bugs in the FHE libraries it tests (report those to the library), and results that depend on parameters you chose.
